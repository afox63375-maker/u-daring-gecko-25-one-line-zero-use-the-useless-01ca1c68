# One Line, Zero Use: The Useless Superpower Sprint

One original line naming a hilariously useless superpower: the gift of
talking to animals, wasted entirely on goldfish with a one-topic mind.

Running `main.py` (Python standard library only) writes the line to
`/output/entry.txt` — exactly one line, no trailing newline.

## The line

> I can talk to animals — but only goldfish, and all they ever want to
> discuss is the plastic castle.

The power sounds grand until the fine print lands: the only minds you
can read belong to creatures with a three-second memory and a single
obsession — the plastic castle in the bowl.
